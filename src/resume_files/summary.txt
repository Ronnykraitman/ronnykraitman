*My AI Journey: Key Projects & Architectures*:



1. **Building the Consumer Agent (E-Commerce Orchestration)**:

(If asked about the distributed architecture I implemented or how I built the consumer agent, base the answer on this):

I built a comprehensive e-commerce shopping agent capable of autonomous, multi-turn workflows. The goal was to create a production-grade orchestration service that could handle high-scale user requests with low latency and zero blocking.

- Core Stack: Python 3.12, FastAPI, and Redis for state management and semantic caching.

- Agentic Framework: LangGraph to construct a stateful graph router. The router dynamically inspects user intent, manages context windows, and dispatches sub-tasks to specialized worker agents executing asynchronously.

- Tools & MCP Integration: Built a modular tool registry for e-commerce capabilities. Integrated RAG (Retrieval-Augmented Generation) for hybrid product discovery and implemented MCP (Model Context Protocol) to standardize tool interfaces and external data connections.

- Performance & Token Optimization: Heavily optimized latency and inference cost through structured prompt engineering, system prompt compression, LLM semantic caching in Redis, and token budgeting.

- Multilingual Attribute Extraction: Solved complex i18n attribute extraction for international e-commerce platforms, enabling flexible product matching across agglutinative and morphologically complex languages.



2. **`agentix-arena` & Automated Evaluation Harness (LLM-as-a-Judge)**:

(If asked about how I evaluate, benchmark, or test LLMs in production):

- Built an asynchronous streaming benchmarking engine (`agentix-arena`) with FastAPI and AWS Bedrock to run side-by-side evaluations of foundation models across throughput (tokens/sec), first-token latency, and response accuracy.

- Designed automated quality gates using LLM-as-a-Judge patterns and custom evaluation metrics to quantify hallucination rates, tool-call fidelity, and schema compliance.

- Optimized CI/CD test runs by crafting pytest fixtures for golden-path regression testing, executing evaluation suites against Bedrock endpoints prior to production deployment.
