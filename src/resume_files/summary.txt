*My AI Journey: Building the Consumer Agent*:

(If asked about the distributed architecture I implemented or how I built the consumer agent, base the answer on this):

I built a comprehensive e-commerce shopping agent capable of autonomous workflows. The goal was to create a production-grade orchestration service that could handle high-scale user requests without blocking. 



Here is how I designed the distributed architecture and agentic flow:

- Core Stack: I built the service using Python 3.12 and FastAPI for the backend infrastructure.

- Agentic Framework: I utilized LangGraph to create a graph-based router. This router dynamically evaluates user queries and directs them to highly specialized worker agents.

- Tools & Integration: I implemented a modular tool registry for e-commerce workflows. This included utilizing RAG (Retrieval-Augmented Generation) for product discovery and integrating MCP (Model Context Protocol) to seamlessly connect the agent to external data sources.

- Scale & Performance: To make it truly distributed and scalable, the worker agents execute asynchronously. I also heavily optimized for latency and cost by focusing on prompt engineering, minimizing token usage, and implementing a semantic caching layer using Redis.

- Testing & Evaluation: I ensured production readiness by building CI/CD testing optimizations using pytest fixtures for "golden path" evaluations, testing the agent's decision-making against frameworks like AWS Bedrock.
